## 4. 다음에 할 일 (우선순위 순)

### 4-1. 운영자 작업 — 이게 유일하게 남은 핵심

현재 '공식자료 기반 가이드'로 표시된 **55건 중 실제로 다녀온 곳부터** 아래를 채웁니다.
채워 넣은 글은 `visitType: 'visited'`, `visitedOn: '방문일'`을 지정하면 배지가
'실제 방문 후기'로 바뀝니다.

- 방문일, 동행 인원, 출발지
- 실제 이동 시간 (구간별)
- 주차 상황 (평일/주말 차이)
- 요금, 운영 시간 (현장 확인 기준)
- 대기 시간, 식사 경험
- 직접 촬영한 사진

**반복 표현 문제가 실질적으로 해결되는 지점입니다.** 현재 `숙소 권역`이 27개 파일에
118회, `대체 코스`가 19개 파일에 54회 나옵니다. 문장을 기계적으로 바꾸면 오히려
대량 생성 신호가 커지므로, 실제 확인한 숫자를 넣는 것이 유일한 해법입니다.

### 4-2. Search Console

`docs/indexing-priority-urls.md` 참고. 요약하면:

1. `https://tourpick360.com/sitemap-index.xml` 재제출
2. 1순위 8건만 URL 검사로 색인 요청 (홈, 방문 후기 5건, 비교 도구, 편집 기준)
3. 배지만 추가된 55건은 수동 요청하지 말고 사이트맵 재크롤에 맡긴다
4. 3~4일 뒤 '찾을 수 없음(404)'이 10건 → 2건으로 줄었는지 확인

### 4-3. 확인이 필요한 미검증 항목

작업 환경에서 `tourpick360.com` 외부 접속이 차단되어 **라이브 화면을 직접 확인하지
못했습니다.** 브라우저에서 눈으로 확인이 필요합니다.

- 메인 후기 카드 5장이 이미지와 함께 정상 표시되는지 (모바일 포함)
- `/tools/itinerary-comparison/` 탭 10개가 뜨고 전환되는지.
  탭이 없이 10개 유형이 세로로 모두 펼쳐져 보이면 JS가 걸리지 않은 상태다
  (내용은 모두 보이므로 치명적이지는 않음)
- `/ads.txt`가 AdSense에서 '찾을 수 없음'으로 계속 뜨는지
- Search Console 404 10건 중 **나머지 2건의 URL** — 8건은 다국어 페이지로 특정했고,
  나머지 2건은 목록을 열어봐야 알 수 있다

## 5. 참고 — GPT 감사 내용에 대한 검증 결과

외부에서 받은 사이트 진단 중 상당수가 이 저장소와 맞지 않았습니다. 다시 같은 지적을
받더라도 아래는 재작업하지 않아도 됩니다.

| 지적 | 검증 결과 |
|---|---|
| 메인의 '참고 사이트 매거진형' 제작 메모 문구 삭제 | 저장소 전체에 해당 문구 없음 |
| 메인에 종료된 6~7월 축제 6건이 남아 있음 | 메인에 축제 일정 자체가 없음 |
| '업데이트 기준: 2026년 6월 18일' 수정 | 해당 문구 없음 |
| 메뉴가 페이지마다 다름 | `BaseLayout.astro` 공통 컴포넌트로 전 페이지 동일 |
| ads.txt 없음 | 저장소·빌드 결과물 모두 정상 (`pub-5804969457082424`) |
| 다국어 페이지 품질 저하 | 라이브에 없음. 과거 삭제된 페이지가 색인에 남아 있던 것 |
| 빈 맛집 카테고리 | 맛집 카테고리 자체가 존재하지 않음 |

지적 근거로 제시된 링크가 301 리디렉션되는 `www.` 주소였습니다. 현재 사이트가 아니라
옛 주소나 Google 색인에 남은 삭제 페이지를 기준으로 작성된 것으로 보입니다.

**단, 아래 두 가지는 지적이 타당했고 이번에 반영했습니다.**

- 실제 방문 후기를 전면에 배치할 것 → 3-1
- 실제 방문과 자료 기반 글을 구분할 것 → 3-6
